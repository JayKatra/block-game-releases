# Block Game - test build


## Get it on Android
**[Download the latest build](https://github.com/JayKatra/block-game-releases/releases/latest/download/block-game.apk)**

1. Open the link above on your Android phone. The file **block-game.apk** downloads.
2. Open the downloaded file (tap the download notification, or find it in **Files > Downloads**).
3. If Android says your browser isn't allowed to install apps, tap **Settings**, turn on **Allow from this source**, then go back.
4. Tap **Install**. If Google Play Protect warns about an unknown app, tap **More details > Install anyway**.
